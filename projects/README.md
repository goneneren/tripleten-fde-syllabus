# Projects: Starter Code & Technical Scaffolds

This directory serves as the placeholder for the actual **technical starter code, seeded defects, and grading rubrics** for the 5-project syllabus.

In the final operational repository structure, this folder will contain:
1. The Docker Compose definitions for the reference platform.
2. The seeded application codebases containing defects that students must repair.
3. The explicit Pass/Fail rubrics defining Must-Have criteria and Recommendations for each project's client defense and PR submission.
4. The published scenario packs, held-out grader packs, emulator `FIDELITY.md` files, and verifier scripts required by [`syllabus/scenario-emulator-delivery.md`](../syllabus/scenario-emulator-delivery.md).

## Current Contract

- [`project-5-rubric.md`](project-5-rubric.md) defines the additional local, protected-AWS, cost, and teardown Must-Haves for the capstone.
- Before a cohort launches, each project delivery repository must provide its required rubric, scenario packs, expected-issue list, and automated checks. This planning repository does not substitute for those runnable artifacts.
