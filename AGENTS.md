# Project Overview: AI Forward Deployed Engineer (AI FDE) Syllabus

## 🎯 Program Vision & Parameters
- **Role Target**: AI Forward Deployed Engineer (AI FDE)
- **Program Duration**: 22 Weeks
- **Student Commitment**: ~20 Hours / Week (Total ~440 hours of study & practical project work)
- **Format**: Bootcamp style (Sprint-based, asynchronous project work combined with live instructor/tutor support, code reviews, and office hours)
- **Primary Goal**: Train job-ready AI Forward Deployed Engineers capable of bridging production AI (LLMs, RAG, Agents, Vector DBs, Fine-Tuning) with real-world enterprise deployment (API integrations, enterprise data pipelines, system architecture, security, evaluation, client delivery, and cloud infrastructure).

---

## 🛠️ What is an AI Forward Deployed Engineer?
An **AI Forward Deployed Engineer (AI FDE)** operates at the intersection of Enterprise Software Engineering, Applied AI/ML, and Solutions Delivery (popularized by companies like Palantir, OpenAI, Anthropic, Scale AI, and Databricks). 
An AI FDE must be able to:
1. **Understand Enterprise Business Logic & Needs**: Scope client problems and translate domain requirements into concrete technical architectures.
2. **Build & Integrate Production AI Systems**: Implement modern LLM pipelines, RAG architectures, multi-agent frameworks, fine-tuned models, and vector stores.
3. **Ship Enterprise-Grade Software**: Write clean, testable code, dockerize services, build robust APIs (REST/gRPC), set up CI/CD, and handle security, governance, and cloud deployment (AWS/GCP/Azure).
4. **Evaluate & Audit AI Systems**: Measure accuracy, hallucination, latency, throughput, token cost, and safety/security vulnerabilities (OWASP for LLMs).
5. **Manage Delivery & Client Iteration**: Work directly with stakeholders, conduct technical scoping, handle edge cases in messy enterprise data, and deliver production-ready software solutions.

## 📋 Methodology & Research Plan

### Phase 1: Competitor & Industry Research (Current Phase)
Investigate top industry bootcamps, AI engineering programs, and enterprise tech roles to benchmark:
1. **Syllabus & Curriculum**: Key topics, technologies, frameworks, depth vs. breadth.
2. **Teaching Methodology**: Asynchronous vs. synchronous, project-based learning, sprint structure, instructor/tutor support mechanisms.
3. **Student Workflow & Submission**: How students submit code (GitHub, LMS platforms, automated grading, manual code reviews), revision cycles, and grading rubrics.
4. **Competitors & Programs to Analyze**:
   - Industry Roles: Palantir FDE, OpenAI/Anthropic Solutions Engineer / FDE, Scale AI Forward Deployed Engineer.
   - Bootcamps & Courses: TripleTen (Software Engineering / Data Science / AI), Maven / AI Maker Academy, CoRise / Maven Applied AI / AI Engineer Bootcamps, General Assembly, Springboard, Fullstack Academy, Weights & Biases Academy, DeepLearning.AI.

### Phase 2: Curriculum Architecture & Sprint Breakdown
- Structure 22 weeks into logical modules / sprints (e.g., 2-week sprints).
- Balance foundational software engineering, enterprise data/APIs, modern AI stack (RAG/Agents/Fine-tuning), evaluation/MLOps, and capstone deployment projects.

### Phase 3: Detailed Syllabus & Project Specifications
- Define learning objectives, project prompts, starter code requirements, submission guidelines, and rubrics for each sprint.

## 🤖 Guidelines for AI Assistants & Contributors
- **Focus on Actionable Enterprise Skills**: Prioritize tools and methodologies actively used by enterprise AI teams (e.g., Python, Docker, FastAPI, LangChain/LlamaIndex/Haystack, AutoGen/CrewAI/LangGraph, Qdrant/Milvus/Pinecone, vLLM/Ollama, MLflow/LangSmith/Phoenis, AWS/GCP, vLLM, Unstructured, TruLens/Ragas).
- **Emphasize Hands-On Projects**: Every module must culminate in a realistic software deliverable simulating client/enterprise deployment scenarios.
- **Support High-Touch Student Experience**: Design rubrics and code-review guidelines tailored for a 20h/week bootcamp with instructor and code reviewer support.
